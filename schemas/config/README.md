# Base configuration schemas

These JSON Schema documents define the public-safe Phase F12 foundation contract. Database, document generation, approved Google Drive filing, the dedicated RC Finance WhatsApp route, and claims are enabled. Claim mutations remain an administrator-only local workflow and add no WhatsApp agent tool capability.

The private Drive destination file is validated against `schemas/drive-folders.schema.json` and remains excluded from Git. OAuth credentials and tokens remain outside the workspace.
